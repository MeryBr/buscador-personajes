# 🔍 Buscador de Personajes

Aplicación web para buscar personajes de anime utilizando la API pública de **Jikan**. Proyecto hecho con **HTML**, **CSS** y **JavaScript** puro.

🌐 [Ver demo en vivo](https://merybr.github.io/buscador-personajes/)

---

## 🧾 Descripción

Este proyecto permite buscar personajes de anime por nombre, mostrando sus imágenes, nombres y animes relacionados.

La información se obtiene desde [Jikan API](https://jikan.moe/), una API no oficial de MyAnimeList.

---

## 🛠️ Tecnologías usadas

- HTML5  
- CSS3 (responsive)  
- JavaScript (Vanilla)  
- Fetch API  
- Jikan API

---

## ✨ Funcionalidades

- Búsqueda de personajes por nombre.
- Visualización de:
  - Imagen del personaje
  - Nombre del personaje
  - Lista de animes donde aparece
- Manejo de errores:
  - Búsqueda vacía
  - Sin resultados encontrados
